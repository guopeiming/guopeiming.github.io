## 本地调试

1. 安装 Ruby
```bash
apt-get install ruby-full
```
2. 安装 Bundler
```bash
bundle install
```
3. 启动调试
```bash
bundle exec jekyll serve
```

Github文档：https://docs.github.com/zh/pages/setting-up-a-github-pages-site-with-jekyll/testing-your-github-pages-site-locally-with-jekyll  
Jekyll文档：https://jekyllrb.com/docs/installation/  
Jekyll-minimal文档：https://github.com/pages-themes/minimal
